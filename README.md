# FluentFrame — AI Video English

MVP aplikacji do nauki angielskiego z filmów YouTube.

## Funkcje MVP

- wklejanie linku i osadzony odtwarzacz YouTube,
- interaktywna przykładowa transkrypcja,
- tłumaczenie słowa po kliknięciu,
- zapisywanie słów lokalnie w przeglądarce,
- widok „Moje słowa”,
- placeholder „Ćwicz z AI”.

## Uruchomienie

```bash
npm install
npm run dev
```
